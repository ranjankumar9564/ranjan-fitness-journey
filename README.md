# Ranjan Fitness Journey

A mobile-first fitness PWA for tracking training, hydration, nutrition, habits, body weight and personal records.

## Features
- Six-day workout split with two leg days and load logging for each exercise.
- Daily hydration tracker with quick-add buttons and undo.
- Food diary with calories, protein, carbs and fat.
- Habit checklist, sleep and step tracking.
- Body-weight history and personal-record log.
- JSON data export.
- Responsive design, custom R brand mark, subtle animations and offline caching.
- Local-first storage: no account, backend or paid service.

## Publish with GitHub Pages
The repository includes a GitHub Actions workflow at `.github/workflows/pages.yml`.
1. Open **Settings → Pages**.
2. Under **Build and deployment**, select **GitHub Actions** as the source.
3. The workflow will deploy the site after the next push or manual run from the Actions tab.

## Add to iPhone
1. Open the published HTTPS Pages URL in Safari.
2. Tap **Share → Add to Home Screen**.
3. If offered, enable **Open as Web App**, then tap Add.

## Data and privacy
Your logs are stored in browser localStorage on that device. They do not sync across devices and may be lost if browser website data is cleared. Use **Progress → Export my data** for a backup. No data is sent to a server.

## Fitness note
Suggested exercise loads are examples, not prescriptions. Choose weights based on ability, technique and recovery. Calorie and hydration needs vary; adjust goals to your circumstances.
